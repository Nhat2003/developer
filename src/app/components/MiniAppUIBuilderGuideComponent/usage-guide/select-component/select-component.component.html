Select Component

Select là component dùng để chọn một hoặc nhiều giá trị trong nhóm các lựa chọn.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
extend ViewProps | any Thuộc tính mở rộng cho View
padding NumberOrString | NumberOrString[] Khoảng cách padding
paddingHorizontal number | string Khoảng cách ngang
paddingVertical number | string Khoảng cách dọc
paddingBottom number | string Khoảng cách phía dưới
paddingTop number | string Khoảng cách phía trên
paddingLeft number | string Khoảng cách trái
paddingRight number | string Khoảng cách phải
margin NumberOrString | NumberOrString[] Khoảng cách margin
marginHorizontal number | string Margin ngang
marginVertical number | string Margin dọc
