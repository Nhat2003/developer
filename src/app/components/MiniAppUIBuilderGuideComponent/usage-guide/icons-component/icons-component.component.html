Icons Component

Icons là component được sử dụng cho việc hiển thị icon trong Mini App.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
style StyleProps<ViewStyle> Style cho icon
source string Đường dẫn hoặc tên icon
size 'tiny' | 'small' | 'medium' | 'large' Kích thước icon
component object Custom component để hiển thị icon
iconContainerStyle string Style cho container chứa icon
title Number | {{'{'}} url: string {{'}'}} Tiêu đề hoặc ảnh tiêu đề cho icon
