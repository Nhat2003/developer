Radio Component

Radio là component dùng để chọn một giá trị trong nhóm các lựa chọn.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
radioButtons RadioButtonProps[] Danh sách các radio button
onPress (id: string) => void Hàm gọi khi chọn một radio button
selectedId string ID của radio button được chọn
layouts row | column (default = column) Kiểu bố cục hiển thị radio buttons
containerStyle StyleProps<ViewStyle> Style cho container chứa radio buttons
