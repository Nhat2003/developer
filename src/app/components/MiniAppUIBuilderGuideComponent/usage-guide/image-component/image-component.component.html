Image Component

Image Component dùng để hiển thị hình ảnh, cho phép người dùng xem hình ảnh với kích thước của màn hình và có thể tương tác thu phóng hình ảnh.

- Thuộc tính của Image Component:

Thuộc tính Kiểu dữ liệu Mô tả

duration number
delay number (default = 0)
isLTR boolean (default = false)
