Button Component

Button thể hiện hành động mà người dùng có thể thực hiện trên UI, gồm có 2 loại:

  • Label button: là button chứa tiêu đề thể hiện hành động mà người dùng có thể thực hiện trên UI

    Hình: Label button

  • Icon button: là button chỉ chứa icon, icon hiển thị thể hiện được hành động mà người dùng có thể thực hiện trên UI

    Hình: Icon button

  • Button component chứa các thuộc tính:
    • Tên thuộc tính Kiểu dữ liệu Mô tả
    extend PressableProps any
    delay number
    padding NumberOrString hoặc NumberOrString [] Kích thước của button
    paddingHorizontal number hoặc string Khoảng cách ngang giữa button
    paddingVertical number hoặc string Khoảng cách dọc giữa button
    paddingHorizontal number hoặc string Khoảng cách ngang giữa button
    paddingBottom number hoặc string
    number hoặc string number hoặc string
    paddingLeft number hoặc string Khoảng cách button với lề trái
    paddingRight number hoặc string Khoảng cách button với lề phải
    margin NumberOrString hoặc NumberOrString []
    number hoặc string number hoặc string
