RangeSlider Component

RangeSlider là component tạo giao diện cho phép người dùng chọn khoảng giá trị trong một giới hạn.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
minimumValue number (default = 0) Giá trị tối thiểu
maximumValue number (default = 1) Giá trị tối đa
value number (default = minimumValue) Giá trị hiện tại
step number Bước nhảy giữa các giá trị
minimumTrackTintColor string (default = 'white') Màu của đoạn thanh trước thumb
maximumTrackTintColor string (default = 'gray') Màu của đoạn thanh sau thumb
thumbTintColor string (default = '#518EFF') Màu thumb
thumbStyle StyleProps<ViewStyle> Style cho thumb
trackStyle StyleProps<ViewStyle> Style cho toàn bộ thanh
minTrackStyle StyleProps<ViewStyle> Style cho phần thanh tối thiểu
maxTrackStyle StyleProps<ViewStyle> Style cho phần thanh tối đa
inverted boolean (default = false) Đảo ngược hướng slider
vertical boolean (default = false) Hiển thị slider dọc
enabled boolean (default = true) Kích hoạt hoặc vô hiệu slider
slideOnTap boolean (default = true) Cho phép di chuyển thumb khi click vào track
trackHeight number (default = 4) Chiều cao thanh
thumbSize number (default = 15) Kích thước thumb
thumbImage Image Ảnh cho thumb
onValueChange (value: number) => void Hàm gọi khi giá trị thay đổi
onSlidingStart (value: number) => void Hàm gọi khi bắt đầu trượt
onSlidingComplete (value: number) => void Hàm gọi khi kết thúc trượt
CustomThumb Class | Function Custom thumb với 2 thuộc tính: value, thumb ('min' hoặc 'max')
…props extends ViewProps Thuộc tính mở rộng
