Toast Component

Toast Component là component trong Super App hỗ trợ show toast message - các thông báo nhanh trên hệ thống.

Thuộc tính của Toast Component:

Tên thuộc tính Kiểu dữ liệu Mô tả
size number (default = 25)
text string
fillColor string (default = #518EFF)
unfillColor string
disableText string
useNativeDriver boolean (default = true)
disableBuildInState boolean
TouchableComponent any component extend Pressable
iconStyle StyleProps<ViewStyle>
style StyleProps<ViewStyle>
textStyle StyleProps<TextStyle>

- Khai báo Component
