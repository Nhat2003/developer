Checkbox Component

Checkbox là component dùng để chọn một hoặc nhiều mục nằm trong nhóm lựa chọn.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
size number (default = 25) Kích thước checkbox
text string Văn bản hiển thị
fillColor string (default = #518EFF) Màu nền khi được chọn
isChecked boolean Trạng thái đã chọn hay chưa
unfillColor string Màu nền khi chưa chọn
disableText string Văn bản khi checkbox bị vô hiệu
bounceEffect {{'{'}} value, velocity, bounciness {{'}'}} Hiệu ứng bật khi click
useNativeDriver boolean (default = true) Sử dụng native driver để tối ưu animation
disableBuildInState boolean Vô hiệu hoá state mặc định
ImageComponent Image Component hình ảnh hiển thị
TouchableComponent Component extends Pressable Component nhận sự kiện nhấn
textComponent ReactNode Component custom hiển thị text
iconStyle StyleProps<ViewStyle> Style cho icon
style StyleProps<ViewStyle> Style container checkbox
textStyle StyleProps<TextStyle> Style cho text
onPress (checked: boolean) => void Hàm gọi khi click
…props BaseTouchableProps Thuộc tính mở rộng
