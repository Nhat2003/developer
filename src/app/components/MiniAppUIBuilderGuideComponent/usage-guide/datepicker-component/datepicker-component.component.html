Datepicker Component

Datepicker là component giao diện cho phép người dùng lựa chọn ngày tháng.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
value Date Giá trị ngày tháng được chọn
onChange function Hàm gọi khi giá trị thay đổi
children React Element Phần tử con hiển thị bên trong Datepicker
mode "time" | "date" | "datetime" Chế độ hiển thị
minDate Date Ngày tối thiểu có thể chọn
maxDate Date Ngày tối đa có thể chọn
fromYear Date Năm bắt đầu cho picker
toYear Date Năm kết thúc cho picker
imprerativeState boolean Điều khiển trạng thái bằng imperative

- Method:

Method Type Mô tả
onClose ref function Hàm đóng Datepicker
