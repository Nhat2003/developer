Timepicker Component

Timepicker là component cho phép người dùng lựa chọn thời gian.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
value Date Giá trị thời gian được chọn
onChange function Hàm được gọi khi thời gian thay đổi
children React Element Phần tử hiển thị bên trong Timepicker
mode time | date | datetime Chế độ chọn thời gian, ngày hoặc cả hai
minDate Date Ngày/thời gian nhỏ nhất cho phép chọn
maxDate Date Ngày/thời gian lớn nhất cho phép chọn
fromYear Date Năm bắt đầu cho lựa chọn
toYear Date Năm kết thúc cho lựa chọn
imprerativeState boolean Kích hoạt trạng thái điều khiển bằng lệnh

- Method:

Method Type Mô tả
onClose ref function Đóng Timepicker thông qua ref
