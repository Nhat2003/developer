Loading Component

Loading Component là component hiển thị giao diện cho biết một tiến trình đang được thực hiện.

- Loading Component gồm các thuộc tính:

Thuộc tính Kiểu dữ liệu Mô tả
style StyleProps<ViewStyle>
show bool | false
size 'tiny' - 'small' - 'medium' - 'large'
padding NumberOrString hoặc NumberOrString[]
paddingHorizontal number hoặc string
paddingVertical number hoặc string
paddingBottom number hoặc string
paddingLeft number hoặc string
paddingRight number hoặc string
margin NumberOrString hoặc NumberOrString[]
