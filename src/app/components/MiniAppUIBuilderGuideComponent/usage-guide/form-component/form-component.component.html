Form Component

Form Component phục vụ cho việc hiển thị và quản lý các biểu mẫu.

- Thuộc tính gồm:

Thuộc tính Kiểu dữ liệu Mô tả
extend ViewProps | any Thuộc tính mở rộng của View hoặc bất kỳ
padding NumberOrString | NumberOrString[] Khoảng đệm toàn bộ
paddingHorizontal number | string Khoảng đệm ngang
paddingVertical number | string Khoảng đệm dọc
paddingBottom number | string Khoảng đệm phía dưới
paddingLeft number | string Khoảng đệm bên trái
paddingRight number | string Khoảng đệm bên phải
margin NumberOrString | NumberOrString[] Khoảng cách bên ngoài
