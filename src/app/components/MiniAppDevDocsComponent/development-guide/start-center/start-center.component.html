Bắt đầu với Mini App Center

Hướng dẫn chi tiết quy trình phát triển Mini App trên hệ thống Mini App Center (MAC) của VNPT.

1.1. Tổng quan quy trình phát triển Mini App

Bước Mô tả
1. Tạo Mini App
  1. Đăng nhập tài khoản nhà phát triển đã đăng ký trên MAC
  2. Tại Danh sách App chọn Thêm ứng dụng và điền thông tin ứng dụng
  3. Tại Danh sách ứng dụng vừa tạo chọn Tạo Mini App

Bây giờ, bạn có thể truy cập vào MAC và tạo các Mini App của mình
2. Xây dựng Mini App
  1. Nhà phát triển tham khảo tài liệu hướng dẫn và công cụ do Super App cung cấp
  2. Nhà phát triển cấu hình các công cụ cần thiết theo thông tin được cung cấp
  3. Nhà phát triển tiến hành phát triển Mini App và export ra file theo định dạng được compile từ hệ thống Super App
  4. Chọn Mini App đã tạo ở bước 1 và chọn Quản lý phiên bản
  5. Tại màn hình Quản lý phiên bản chọn Tạo phiên bản mới
  6. Điền các thông tin cho phiên bản Mini App và upload các file vừa export lên hệ thống
3. Kiểm duyệt Mini App

Tại phiên bản Mini App vừa tạo, chọn Gửi xét duyệt.

→ Sau khi gửi xét duyệt, bộ phận Tester sẽ kiểm duyệt MiniApp đáp ứng tiêu chuẩn quy định của hệ thống.

Nếu MiniApp đạt tiêu chuẩn chất lượng, Tester thực hiện phê duyệt sẵn sàng phát hành.
4. Phát hành Mini App

Tại phiên bản đủ điều kiện và đã được hệ thống phê duyệt, chọn Xuất bản phiên bản này.

→ Mini App của bạn lúc này đã được xuất bản lên app Super App và bạn có thể trải nghiệm Mini App của mình trên ứng dụng này

1.3.2.1. Mini App Source Base

Mini App Source Base là bộ khung cho việc phát triển các Mini App

File/Folder Description
app.json File contains the Mini App configuration: AppId, BundleId, InputFile, Name App, Version
babel.config.js File contains the Babel configuration
index.js File contains root index script
metro.config.js File contains the metro configuration
package.json File contains npm packages used in the Mini App and Script CLI for development.
webpack.config.mjs File contains Webpack config
src Folder contains Mini App screens
com_miniapp_myapp_1_0_0.tsx File contains start point of Mini App.
dependencies.mjs File chứa các thư viện mà Host App đang hỗ trợ, có yêu cầu version tương ứng. Mini app muốn chạy tốt trên môi trường Host App cần phải sử dụng đúng những version yêu cầu.
assets Folder contains Assets
screens Folder contains Mini App screens

Hướng dẫn cấu hình trên mini app source base

  • Download mini app source base: https://gitlab.com/software.media/_miniapp.git
  • Công cụ lập trình IDE: Develop có thể sử dụng 1 số IDE hỗ trợ lập trình ứng dụng trên platform React Native như: VSCode, Atom, …, tuy nhiên để dễ dàng cho việc support và tương thích môi trường nền tảng chúng tôi khuyến nghị dùng VSCode.
  • Cấu hình BundleId: Vào file app.json để khai điền bundleId cho ứng dụng. BundleId này là để định danh cho 1 mini app. Được đăng ký trước trên MAC, và phải được đảm bảo là duy nhất và không đã được sử dụng với mini app khác.
  • Cấu hình ModuleId: Vào file webpack.config.mjs thay thế moduleid định danh cho mini app. Hiện tại đang được đặt mặc định là com_miniapp_myapp_module. Hãy đổi lại theo syntax của bundleId. Ví dụ: bundleId (com.abc.news) → com_abc_news_module.
  • Cấu hình InputFile: Đổi tên file com_miniapp_myapp_1_0_0.tsx mặc định thành tên input riêng của mini app theo cấu trúc của Bundle Id + Version. Thay các dấu "." băng dấu "_". Đồng thời khai báo InputFile vào trong App.json. Mỗi khi release version mới đều cần đổi lại tên file theo version mới của app. Vd: bundleId (com.abc.news) + version (1.0.1) → com_abc_news_1_0_1

Hướng dẫn xây dựng ứng dụng từ source base

  • Chạy lệnh Yarn: Sau khi cài đặt xong môi trường, mở project bằng VSCode. Mở terminal ở bên dưới IDE và gõ lệnh Yarn để cài đặt các thư viện cần thiết. Nếu máy chưa đc cài đặt yarn thì có thể setup theo hướng dẫn.
  • Các lệnh hỗ trợ đã được tích hợp sẵn trên source base:
    • yarn start: Lệnh khởi chạy node server cho ứng dụng react native.
    • yarn run-ios: Lệnh chạy trên simulator trên ios.
    • yarn run-android: Lệnh chạy trên android.
    • yarn build: Lệnh build bundle để up lên MAC.

Hướng dẫn build release Mini App

Sau khi quá trình develop 1 mini app hoàn thành, nhà phát triển mong muốn build mini app để upload lên MAC. Thì cần thực hiện các bước sau:

  • Vào thư mục build trong source base xoá các version build cũ.
  • Chạy lệnh yarn build để build source code. Sau khi chạy xong trong thư mục build sẽ hiện ra 4 file (như hình dưới). Trong thư mục build sẽ có các folder như ios, android, output. Tuy nhiên bạn chỉ cần chọn 4 file trong trong thư mục build/outputs/ios/remotes/ để upload lên MAC.

1.3.2.3. Mini App API

Mini App API cung cấp các API để nhà phát triển có thể tương tác với Super App. Một số API sẽ yêu cầu nhà phát triển gửi xét duyệt trước khi được sử dụng.

Mini App API sẽ được cài tự động khi nhà phát triển tạo mới một Mini App

• Tên thư viện:

-mini-api (https://www.npmjs.com/package/-mini-api)

• Cài đặt

Mặc định đã được khai báo trong file package.json trong souce base. Tuy nhiên có thể chưa phải bản mới nhất. Để sử dụng thư viện phiên bản mới nhất vào file package.json xoá dòng -mini-api trong mục dependencies.

yarn add -mini-api
